Assumptions & non-goals
  • Independent reference model: stationary Zipf popularity, Poisson arrivals; no bursts, trends or temporal locality.
  • All objects have the same size, plus 100 B of per-key Redis overhead.
  • Redis runs allkeys-lru as exact LRU with immediate expiry. Real Redis samples 5 keys and expires lazily, and its default policy is noeviction, which rejects writes once memory is full.
  • The TTL is set when a key is filled and is not reset by hits, unlike the classic Che TTL cache.
  • Writes follow the read popularity. ttl-only: writes go to the database only and the cached copy stays stale until it expires or is evicted. invalidate: writes delete the cached key.
  • Latencies are log-normal fits to P50/P99. A miss pays Redis P50 plus the database; while Redis is down every read pays the client timeout plus the database.
  • Database latency does not grow with load; overload is reported as utilisation only.
  • Non-goals: key design, penetration / avalanche / stampede, multi-tier caches, replica lag, variable object sizes, non-stationary traffic.
